# email/optech-email1/

Header images for the OPTECH 2026 "Email 1 (no report)" campaign in Instantly.
One image per community: the AI answer card shows that community's name.
Each lead's `hero_url` field points at its file through jsDelivr, pinned to
the commit that added it. Never edit or delete a file once it has been sent;
add a new file instead.
